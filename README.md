# Mahadev Property

Premium real-estate & property development website for **Mahadev Property** — Malad West, Mumbai. Built with TanStack Start, React 19, Tailwind CSS, Framer Motion, GSAP and React Three Fiber.

## Pages

- `/` — Home: hero, search dashboard, RENT carousel, Our Work Process, SALE film-strip carousel, reviews
- `/sale` — sale listings with filters
- `/rent` — rental listings with filters
- `/property/:id` — property detail with private site-visit booking (WhatsApp)
- `/about` — studio story, journey, work process, gallery, FAQs
- `/services` — the 7 services with per-service visuals + EMI calculator
- `/contact` — briefing form (submits to WhatsApp with details pre-filled)
- `/privacy-policy`, `/terms-of-service`, `/gdpr-compliance` — legal pages, linked from the footer

## Development

Requires Node.js and npm.

```sh
npm i
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```
